## Context

What is the issue we're seeing that motivates this decision? What forces — technical, business, organizational — are in tension? State the problem neutrally, without arguing for the answer yet.

## Decision

What did we decide? State it as a clear, active-voice statement: "We will ...". If there were alternatives seriously considered, name them here too, even briefly — the Consequences section is where their trade-offs get compared against the chosen path.

## Consequences

What becomes easier or harder as a result of this decision? Include both the benefits (+) and the costs (−) honestly — an ADR that only lists upsides isn't a useful record for the next engineer deciding whether the trade-off still holds. If the decision was a close call, say so, and say what would change the calculus.
