# Navium Billing SaaS

Multi-tenant billing system for Indian tours and travel agencies.

## Structure

- `billing-backend/` — Node.js + Express + PostgreSQL (production-ready, 422 checks green)
- `billing-frontend/` — React + Vite + TypeScript (in development)
